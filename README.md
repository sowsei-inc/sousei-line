# Sousei-line

Sousei-line is the software production and verification process used by 株式会社創正 (Sowsei Inc.).

AI can produce software quickly. The harder question for us is different:

> If the person responsible for shipping the product cannot reliably review the code itself, what evidence should exist before that exact revision is adopted?

Sousei-line treats implementation, deterministic CI, requirements review, independent verification, human adoption, deployment, and production verification as distinct stages bound to explicit artifact identity.

This repository is being bootstrapped from the production process already exercised on a live product. Public contracts, evidence examples, limitations, and reproducible workflow will be added through reviewable changes.

## Status

Bootstrap in progress. Do not infer guarantees beyond the documents and evidence committed to this repository.
